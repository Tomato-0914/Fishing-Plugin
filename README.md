# 🎣 Fishing-Plugin

Yunzai V3（Miao-Yunzai / TRSS-Yunzai）QQ 群钓鱼小游戏插件。

抛竿 → 等待咬钩 → 及时收杆，钓上鱼虾蟹、海洋垃圾，或者……隐藏款。
支持出售鱼护里的鱼、日/周/月排行榜、称号系统，QQBot 协议下附带快捷按钮。

## 安装

在 Yunzai 根目录执行：

```bash
git clone https://github.com/Tomato-0914/Fishing-Plugin.git ./plugins/Fishing-Plugin
```

无需额外安装依赖（`yaml` 由 Yunzai 提供），重启 Bot 即可。

## 指令

| 指令 | 说明 |
| --- | --- |
| `#钓鱼` / `#抛竿` / `🎣` | 甩出鱼竿（消耗 1 个鱼饵），随机 3~18 秒后浮漂下沉 |
| `#收杆` | 咬钩后 15 秒内收杆；太早空手，太晚鱼跑了 |
| `#打卡` / `#签到` | 每日打卡，抽取幸运值（影响当天钓鱼概率）并送 3 个鱼饵 |
| `#今日欧皇` / `#今日非酋` | 当天首个幸运值 ≥95 / ≤5 的人 |
| `#幸运值排行榜 [非酋]` | 今日幸运值排行（群内为本群） |
| `#历史幸运值` | 最近 30 次打卡记录 |
| `#让我看看你的卡 @某人` | 查看别人今天的幸运值 |
| `#我的鱼护` | 查看鱼护（图片），显示全部出售可得金币 |
| `#出售 名称 [数量]` | 出售鱼护里指定的鱼，不写数量卖全部 |
| `#一键出售` | 出售鱼护里全部有价值的鱼 |
| `#清理垃圾` / `#回收垃圾` | 集中清理海洋垃圾，累计 50 件获得称号【海洋卫士】 |
| `#钓鱼信息` / `#我的金币` | 金币与钓鱼统计 |
| `#钓鱼图鉴` | 全部物品一览（未钓到的显示为灰色） |
| `#钓鱼图鉴 名称` | 物品详情：介绍、栖息地、出现概率、各体型重量与售价、个人记录 |
| `#我的称号` | 称号进度与效果 |
| `#钓鱼排行榜` | 本群今日排行（按钓获总价值） |
| `#钓鱼周排行榜` / `#钓鱼月排行榜` | 本群本周 / 本月排行 |
| `#钓鱼总榜` | 所有群累计排行前 30 名（另有 `#钓鱼总日榜/总周榜/总月榜`） |
| `#钓鱼帮助` | 帮助图（6:00~18:00 白版，其余时间黑版） |
| `#钓鱼更新` / `#钓鱼强制更新` | 主人专用 |

## 玩法数值（默认）

| 结果 | 概率 | 中体型售价 |
| --- | --- | --- |
| 什么都没钓到 | 15% | — |
| 海洋垃圾 | 20% | 0 |
| 普通 N | 30% | 2 ~ 6 |
| 优良 R | 18% | 12 ~ 22 |
| 稀有 SR | 10% | 30 ~ 55 |
| 史诗 SSR | 5% | 80 ~ 150 |
| 传说 UR | 1.94% | 300 ~ 500 |
| 隐藏：人民碎片 | 0.05% | 自动报警，奖励 5000 金币 |
| 隐藏：海洋之心 | 0.01% | 8888 |

鱼分 **小 / 中 / 大** 三种体型（55% / 35% / 10%），售价倍率 0.8 / 1.0 / 1.5。
物品池不包含中华鲟、江豚等保护动物。

## 鱼饵

- 第一次发送 `#钓鱼` 会收到欢迎提示并获赠 **10 个鱼饵**，随后正常抛竿。已经抛过竿的老用户不赠送。
- 每次抛竿消耗 1 个鱼饵（收杆过早、鱼跑了也算用掉）。
- 鱼饵 **2 金币/个**，钓一条普通鱼就能回本。
- 防卡死：鱼饵用完、金币不够、鱼护里也没有能卖的鱼时，每天可领取 5 个救济鱼饵。

## 渔具商店

渔具为**升级制**：全部从 Lv1 开始，必须逐级购买，买了自动装备。每类渔具只负责一类效果：

| 渔具 | 效果 | Lv2 → Lv5 价格 |
| --- | --- | --- |
| 🎣 鱼竿 | 稀有以上、大体型概率提升 | 玻纤竿 500 · 碳纤竿 2000 · 高模碳竿 6000 · 星陨竿 18000 |
| 🧵 鱼线 | 降低断线概率（最多 -90%） | 碳氟线 300 · 编织线 1200 · 复合编织线 3500 · 龙筋线 10000 |
| 🎈 浮漂 | 空军概率降低、收杆时间延长 | 杉木漂 200 · 纳米漂 800 · 芦苇漂 2500 · 月光漂 8000 |
| 🧺 鱼护 | 容量 200 → 1200，Lv4 起出售加成 | 加厚 300 · 速干 1200 · 活水 4000 · 潮汐 10000 |

**鱼饵**（每竿 1 个，同时只用一种，用完自动换成有库存的）：普通饵 2（无效果）· 蚯蚓 4（咬钩更快、少空军）· 腥香饵 6（少垃圾）· 活虾 10（大体型多）· 金丝秘饵 25（稀有多）。

**断线**：收杆时，史诗鱼 6%、传说鱼 12%、大体型额外 +4% 的概率挣断鱼线跑掉。普通的中小鱼、垃圾、隐藏款不会断线。

渔具、称号、打卡运势叠加后有概率下限（空军 ≥3%、垃圾 ≥5%、普通 ≥5%，见 `config.yaml` 的 `limits`）。
价格与效果都在 `config/default_config/shop.yaml`，设计说明见 [docs/SHOP_DESIGN.md](docs/SHOP_DESIGN.md)。

| 指令 | 说明 |
| --- | --- |
| `#渔具商店` | 商店图片：当前等级、下一级价格与效果、鱼饵 |
| `#升级鱼竿` / `#升级鱼线` / `#升级浮漂` / `#升级鱼护` | 购买下一级 |
| `#购买鱼饵 [种类] [数量]` | 如 `#购买鱼饵 蚯蚓 20`，不写种类为普通饵，不写数量为 10 |
| `#使用鱼饵 种类` | 切换当前鱼饵 |
| `#我的鱼饵` / `#我的渔具` | 鱼饵库存 / 装备与总加成 |

## 每日打卡

玩法参考 [Gi-plugin](https://github.com/qiannqq/Gi-plugin) 的每日打卡：每天一次，随机幸运值 0~100。幸运值 ≤10 时会先劝退一次，再发一遍才揭晓。

幸运等级会**轻微**影响当天的钓鱼概率（不打卡没有影响）：

| 幸运值 | 等级 | 当天钓鱼影响 |
| --- | --- | --- |
| 90~100 | 🌟 大吉 | 稀有以上概率 +10%，空军 -2% |
| 70~89 | 🍀 吉 | 稀有以上概率 +5% |
| 30~69 | 🌤️ 平 | 无 |
| 10~29 | 🌧️ 凶 | 空军 +2% |
| 0~9 | ⛈️ 大凶 | 空军 +3%，垃圾 +2% |

等级划分和效果可在 `config.yaml` 的 `checkin.tiers` 中修改。与 Gi-plugin 的详细对比见 [docs/GI_COMPARE.md](docs/GI_COMPARE.md)。

## 称号

称号只能获得一次，拥有即永久生效；重复达成条件（如再次钓到人民碎片）只给金币。

| 称号 | 条件 | 效果 |
| --- | --- | --- |
| 🌱 初出茅庐 | 累计抛竿 10 次 | 咬钩等待 -1s |
| 🎣 熟练钓手 | 累计钓到 100 条鱼 | 收杆时间 +5s |
| 🌊 海洋卫士 | 累计清理 50 件垃圾 | 空军概率 -5%，垃圾概率 -3% |
| 👮 热心市民 | 钓到人民碎片 | 出售金币 +5% |
| 💎 深海之子 | 钓到海洋之心 | 稀有以上概率 +20% |
| 🐉 传说猎人 | 累计钓到 5 条传说鱼 | 大体型概率 +10% |
| ✈️ 空军司令 | 空军/跑鱼/收杆过早累计 100 次 | 挂鱼饵时间 -3s |
| 📖 图鉴大师 | 集齐全部鱼类 | 出售金币 +10% |

## 配置

- 锅巴：可修改开关、钓鱼节奏、各项概率、体型、警局奖励、排行人数、群黑白名单。
- 手动：`config/default_config/` 为默认配置，复制到 `config/config/` 后修改。
  - `config.yaml` 按字段合并，只写要改的项即可
  - `items.yaml`（物品池）、`titles.yaml`（称号）、`help.yaml`（帮助图）整份替换

## 数据

默认存入 SQLite 数据库 `data/fishing.db`（每个用户一行），所有群共享。
QQBot 协议下已绑定 QQ 的用户使用 QQ 号，未绑定时使用 openid。

- 数据库驱动：优先使用 Yunzai 自带的 `sqlite3`，其次 Node ≥ 22.5 内置的 `node:sqlite`；都不可用时自动退回 YAML 存档。
- 也可在 `config.yaml` 中设置 `storage: yaml`，改为每人一个 `data/Fishing_<QQ号>.yaml`。
- **从旧版本升级**：启动时会自动把 `data/` 下的 `Fishing_*.yaml` 导入数据库，原文件移到 `data/yaml_backup_<时间>/`（不会删除）。

| 指令（主人） | 说明 |
| --- | --- |
| `#钓鱼存储状态` | 当前存储方式与存档数量 |
| `#钓鱼数据迁移` | 把 `data/` 下的 YAML 存档导入数据库，数据库已有的用户跳过 |
| `#钓鱼数据迁移覆盖` | 同上，但用 YAML 覆盖数据库中的同名存档 |
| `#钓鱼数据导出` | 把数据库导出为 YAML 到 `data/yaml_export_<时间>/`（备份或切回 YAML 用） |

## 按钮

仅 QQBot 协议（[QQBot-Plugin](https://github.com/Tomato-0914/QQBot-Plugin)）会附带按钮，其他协议不发送。
“收杆”按钮仅限抛竿者本人点击。

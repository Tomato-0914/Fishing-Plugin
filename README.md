# 🎣 Fishing-Plugin

Yunzai V3（Miao-Yunzai / TRSS-Yunzai）QQ 群钓鱼小游戏插件。

抛竿 → 等待咬钩 → 及时收杆，钓上鱼虾蟹、海洋垃圾，或者……隐藏款。
支持出售鱼护里的鱼、日/周/月排行榜、称号系统，QQBot 协议下附带快捷按钮。

## 安装

在 Yunzai 根目录执行：

```bash
git clone https://github.com/Tomato-0914/Fishing-Plugin.git ./plugins/Fishing-Plugin
```

无需额外安装依赖（`yaml` 由 Yunzai 提供），重启 Bot 即可。

## 指令

| 指令 | 说明 |
| --- | --- |
| `#钓鱼` / `#抛竿` / `🎣` | 甩出鱼竿（消耗 1 个鱼饵），随机 3~18 秒后浮漂下沉 |
| `#收杆` | 咬钩后 15 秒内收杆；太早空手，太晚鱼跑了 |
| `#十连钓鱼` | 一次抛出 10 竿（每竿 1 个鱼饵），3~8 秒后自动收网统一结算，之后挂鱼饵 100 秒 |
| `#打卡` / `#签到` | 每日打卡，抽取幸运值（影响当天钓鱼概率）并送 3 个鱼饵 |
| `#今日欧皇` / `#今日非酋` | 当天首个幸运值 ≥95 / ≤5 的人 |
| `#幸运值排行榜 [非酋]` | 今日幸运值排行（群内为本群） |
| `#历史幸运值` | 最近 30 次打卡记录 |
| `#让我看看你的卡 @某人` | 查看别人今天的幸运值 |
| `#我的鱼护` | 查看鱼护（图片），显示全部出售可得金币 |
| `#出售 名称 [数量]` | 出售鱼护里指定的鱼，不写数量卖全部 |
| `#一键出售` | 出售鱼护里全部有价值的鱼 |
| `#清理垃圾` / `#回收垃圾` | 集中清理海洋垃圾，累计 50 件获得称号【海洋卫士】 |
| `#钓鱼信息` / `#我的金币` | 金币与钓鱼统计 |
| `#钓鱼图鉴` | 全部物品一览（未钓到的显示为灰色） |
| `#钓鱼图鉴 名称` | 物品详情：介绍、栖息地、出现概率、各体型重量与售价、个人记录 |
| `#我的称号` | 称号进度与效果 |
| `#钓鱼排行榜` | 本群今日排行（按钓获总价值） |
| `#钓鱼周排行榜` / `#钓鱼月排行榜` | 本群本周 / 本月排行 |
| `#钓鱼总榜` | 所有群累计排行前 30 名（另有 `#钓鱼总日榜/总周榜/总月榜`） |
| `#钓鱼帮助` | 帮助图（6:00~18:00 白版，其余时间黑版） |
| `#钓鱼更新` / `#钓鱼强制更新` | 主人专用 |

## 玩法数值（默认）

| 结果 | 概率 | 中体型售价 |
| --- | --- | --- |
| 什么都没钓到 | 15% | — |
| 海洋垃圾 | 20% | 0 |
| 普通 N | 30% | 2 ~ 6 |
| 优良 R | 18% | 12 ~ 22 |
| 稀有 SR | 10% | 30 ~ 55 |
| 史诗 SSR | 5% | 80 ~ 150 |
| 传说 UR | 1.94% | 300 ~ 500 |
| 隐藏：人民碎片 | 0.05% | 自动报警，奖励 5000 金币 |
| 隐藏：海洋之心 | 0.01% | 8888 |

鱼分 **小 / 中 / 大** 三种体型（55% / 35% / 10%），售价倍率 0.8 / 1.0 / 1.5。
物品池不包含中华鲟、江豚等保护动物。

## 鱼饵

- 第一次发送 `#钓鱼` 会收到欢迎提示并获赠 **10 个鱼饵**，随后正常抛竿。已经抛过竿的老用户不赠送。
- 每次抛竿消耗 1 个鱼饵（收杆过早、鱼跑了也算用掉）。
- 鱼饵 **2 金币/个**，钓一条普通鱼就能回本。
- 防卡死：鱼饵用完、金币不够、鱼护里也没有能卖的鱼时，每天可领取 5 个救济鱼饵。

## 渔具工坊与鱼饵商店

**渔具工坊**负责升级渔具，**鱼饵商店**只卖鱼饵。

渔具为**升级制**：共 **5 件**（鱼竿、鱼线、鱼钩、浮漂、鱼护），每件 **10 级**，全部从 Lv1 开始，必须逐级购买，买了自动装备。每类渔具只负责一类效果：

| 渔具 | 效果 | Lv2 → Lv5 | Lv6 → Lv10 | Lv10 效果 |
| --- | --- | --- | --- | --- |
| 🎣 鱼竿 | 稀有度加成（主力）、大体型概率 | 玻纤竿 500 · 碳纤竿 2000 · 高模碳竿 6000 · 星陨竿 18000 | 流光竿 25000 · 玄冰竿 35000 · 雷霆竿 48000 · 凤翎竿 64000 · 龙骨神竿 85000 | 优良+1.2% 稀有+15% 史诗+11.4% 传说+4.2%，大体型 +20% |
| 🧵 鱼线 | 降低断线概率，少量稀有度加成 | 碳氟线 300 · 编织线 1200 · 复合编织线 3500 · 龙筋线 10000 | 冰蚕丝线 14000 · 金蛛丝线 19000 · 星河线 26000 · 凤羽丝线 35000 · 混沌神丝 46000 | 不再断线；稀有+3% 史诗+2.3% 传说+0.8% |
| 🪝 鱼钩 | 没及时收杆也不跑鱼，少量稀有度加成 | 袖钩 300 · 倒刺钩 1000 · 碳钢钩 3000 · 钛合金钩 8000 | 寒铁钩 12000 · 玄晶钩 16000 · 星芒钩 22000 · 凤喙钩 30000 · 龙牙神钩 40000 | 没及时收杆时 90% 不跑鱼；稀有+3% 史诗+2.3% 传说+0.8% |
| 🎈 浮漂 | 稀有度加成、收杆时间延长 | 杉木漂 200 · 纳米漂 800 · 芦苇漂 2500 · 月光漂 8000 | 星辰漂 11000 · 极光漂 15000 · 鲛珠漂 20000 · 灵犀漂 27000 · 天眼漂 36000 | 稀有+5% 史诗+3.8% 传说+1.4%，收杆 +12s，咬钩 -2s |
| 🧺 鱼护 | 容量、出售加成，少量稀有度加成 | 加厚 300 · 速干 1200 · 活水 4000 · 潮汐 10000 | 深潜 13000 · 碧波 17000 · 沧澜 23000 · 龙宫 30000 · 四海 40000 | 容量 3000，出售 +12%；稀有+2% 史诗+1.5% 传说+0.6% |

五件渔具全部升到 10 级共需 829,800 金币。

**稀有度加成**随等级整体上移：低等级加普通、优良，从 5 级起逐渐转为稀有、史诗，9 级起加传说，普通和优良的加成逐渐取消。
加的是百分点，从比它低的档位按 **空军 → 垃圾 → 普通 → 优良** 的顺序扣除（下限 3% / 5% / 5% / 8%；史诗、传说加成在最后还会从稀有里扣，稀有下限 15%），史诗和传说不会被扣：
渔具越好，先没了空军和垃圾，然后越来越难钓到低级鱼。`#我的渔具` 会显示当前实际概率。

| Lv3 | 6% | 20% | 35.6% | 21.4% | 10% | 5% | 1.9% |
| Lv5 | 3% | 15.2% | 33.4% | 24.7% | 15.6% | 6.1% | 1.9% |
| Lv7 | 3% | 5.1% | 30% | 23.6% | 24.6% | 10.6% | 3% |
| Lv9 | 3% | 5% | 9.9% | 21.4% | 33.5% | 20.7% | 6.4% |
| Lv10 | 3% | 5% | 5% | 12.9% | 38% | 26.3% | 9.7% |
| Lv10 + 混元仙饵 | 3% | 5% | 5% | 8% | 37.9% | 26.3% | 14.7% |

使用或购买第 N 级鱼饵，需要**至少一件渔具达到 N 级**；等级不够时买不了，已囤的保留在库存里，抛竿时自动换成能用的最高级鱼饵。

## 每日打卡

玩法参考 [Gi-plugin](https://github.com/qiannqq/Gi-plugin) 的每日打卡：每天一次，随机幸运值 0~100。幸运值 ≤10 时会先劝退一次，再发一遍才揭晓。

幸运等级会**轻微**影响当天的钓鱼概率（不打卡没有影响）：

| 幸运值 | 等级 | 当天钓鱼影响 |
| --- | --- | --- |
| 90~100 | 🌟 大吉 | 稀有以上概率 +10%，空军 -2% |
| 70~89 | 🍀 吉 | 稀有以上概率 +5% |
| 30~69 | 🌤️ 平 | 无 |
| 10~29 | 🌧️ 凶 | 空军 +2% |
| 0~9 | ⛈️ 大凶 | 空军 +3%，垃圾 +2% |

等级划分和效果可在 `config.yaml` 的 `checkin.tiers` 中修改。与 Gi-plugin 的详细对比见 [docs/GI_COMPARE.md](docs/GI_COMPARE.md)。

## 称号

称号只能获得一次，拥有即永久生效；重复达成条件（如再次钓到人民碎片）只给金币。

| 称号 | 条件 | 效果 |
| --- | --- | --- |
| 🌱 初出茅庐 | 累计抛竿 10 次 | 咬钩等待 -1s |
| 🎣 熟练钓手 | 累计钓到 100 条鱼 | 收杆时间 +5s |
| 🌊 海洋卫士 | 累计清理 50 件垃圾 | 空军概率 -5%，垃圾概率 -3% |
| 👮 热心市民 | 钓到人民碎片 | 出售金币 +5% |
| 💎 深海之子 | 钓到海洋之心 | 稀有以上概率 +20% |
| 🐉 传说猎人 | 累计钓到 5 条传说鱼 | 大体型概率 +10% |
| ✈️ 空军司令 | 空军/跑鱼/收杆过早累计 100 次 | 挂鱼饵时间 -3s |
| 📖 图鉴大师 | 集齐全部鱼类 | 出售金币 +10% |

## 配置

- 抛竿配图：`#钓鱼` 默认发送 `resources/img/cast.jpg`，`#十连钓鱼` 默认发送 `resources/img/multi.jpg`，可在锅巴或 `config.yaml` 的 `fishing.castImage` / `fishing.multiImage` 中换成自己的图片，留空则不发送。
  图片和文字合成一条消息、图片在上。QQBot 需要在 QQBot.yaml 中开启 `markdownImage: true`；未开启时 QQ 会把文字排在图片上方，插件会改为先单独发图片、再发文字。

- 锅巴：可修改开关、钓鱼节奏、各项概率、体型、警局奖励、排行人数、群黑白名单。
- 手动：`config/default_config/` 为默认配置，复制到 `config/config/` 后修改。
  - `config.yaml` 按字段合并，只写要改的项即可
  - `items.yaml`（物品池）、`titles.yaml`（称号）、`help.yaml`（帮助图）整份替换

## 数据

默认存入 SQLite 数据库 `data/fishing.db`（每个用户一行），所有群共享。
QQBot 协议下已绑定 QQ 的用户使用 QQ 号，未绑定时使用 openid。

- 数据库驱动：优先使用 Yunzai 自带的 `sqlite3`，其次 Node ≥ 22.5 内置的 `node:sqlite`；都不可用时自动退回 YAML 存档。
- 也可在 `config.yaml` 中设置 `storage: yaml`，改为每人一个 `data/Fishing_<QQ号>.yaml`。
- **从旧版本升级**：启动时会自动把 `data/` 下的 `Fishing_*.yaml` 导入数据库，原文件移到 `data/yaml_backup_<时间>/`（不会删除）。

| 指令（主人） | 说明 |
| --- | --- |
| `#钓鱼存储状态` | 当前存储方式与存档数量 |
| `#钓鱼数据迁移` | 把 `data/` 下的 YAML 存档导入数据库，数据库已有的用户跳过 |
| `#钓鱼数据迁移覆盖` | 同上，但用 YAML 覆盖数据库中的同名存档 |
| `#钓鱼数据导出` | 把数据库导出为 YAML 到 `data/yaml_export_<时间>/`（备份或切回 YAML 用） |

## 按钮

仅 QQBot 协议（[QQBot-Plugin](https://github.com/Tomato-0914/QQBot-Plugin)）会附带按钮，其他协议不发送。
“收杆”按钮仅限抛竿者本人点击。

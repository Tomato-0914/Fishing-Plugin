# 🎣 Fishing-Plugin

Yunzai V3（Miao-Yunzai / TRSS-Yunzai）QQ 群钓鱼小游戏插件。

抛竿 → 等待咬钩 → 及时收杆，钓上鱼虾蟹、海洋垃圾，或者……隐藏款。
支持鱼获出售、日/周/月排行榜、称号系统，QQBot 协议下附带快捷按钮。

## 安装

在 Yunzai 根目录执行：

```bash
git clone https://github.com/Tomato-0914/Fishing-Plugin.git ./plugins/Fishing-Plugin
```

无需额外安装依赖（`yaml` 由 Yunzai 提供），重启 Bot 即可。

## 指令

| 指令 | 说明 |
| --- | --- |
| `#钓鱼` / `#抛竿` / `🎣` | 甩出鱼竿，随机 3~18 秒后浮漂下沉 |
| `#收杆` | 咬钩后 15 秒内收杆；太早空手，太晚鱼跑了 |
| `#鱼获` | 查看鱼护（图片），显示全部出售可得金币 |
| `#出售 名称 [数量]` | 出售指定鱼获，不写数量卖全部 |
| `#一键出售` | 出售全部有价值的鱼获 |
| `#丢弃垃圾` / `#清理垃圾` | 集中清理海洋垃圾，累计 50 件获得称号【海洋卫士】 |
| `#钓鱼信息` / `#我的金币` | 金币与钓鱼统计 |
| `#钓鱼图鉴` | 已解锁物品一览 |
| `#我的称号` | 称号进度与效果 |
| `#钓鱼排行榜` | 本群今日排行（按钓获总价值） |
| `#钓鱼周排行榜` / `#钓鱼月排行榜` | 本群本周 / 本月排行 |
| `#钓鱼总榜` | 所有群累计排行前 30 名（另有 `#钓鱼总日榜/总周榜/总月榜`） |
| `#钓鱼帮助` | 帮助图（6:00~18:00 白版，其余时间黑版） |
| `#钓鱼更新` / `#钓鱼强制更新` | 主人专用 |

## 玩法数值（默认）

| 结果 | 概率 | 中体型售价 |
| --- | --- | --- |
| 什么都没钓到 | 15% | — |
| 海洋垃圾 | 20% | 0 |
| 普通 N | 30% | 2 ~ 6 |
| 优良 R | 18% | 12 ~ 22 |
| 稀有 SR | 10% | 30 ~ 55 |
| 史诗 SSR | 5% | 80 ~ 150 |
| 传说 UR | 1.94% | 300 ~ 500 |
| 隐藏：人民碎片 | 0.05% | 自动报警，奖励 5000 金币 |
| 隐藏：海洋之心 | 0.01% | 8888 |

鱼分 **小 / 中 / 大** 三种体型（55% / 35% / 10%），售价倍率 0.8 / 1.0 / 1.5。
物品池不包含中华鲟、江豚等保护动物。

## 称号

称号只能获得一次，拥有即永久生效；重复达成条件（如再次钓到人民碎片）只给金币。

| 称号 | 条件 | 效果 |
| --- | --- | --- |
| 🌱 初出茅庐 | 累计抛竿 10 次 | 咬钩等待 -1s |
| 🎣 熟练钓手 | 累计钓到 100 条鱼 | 收杆时间 +5s |
| 🌊 海洋卫士 | 累计清理 50 件垃圾 | 空军概率 -5%，垃圾概率 -3% |
| 👮 热心市民 | 钓到人民碎片 | 出售金币 +5% |
| 💎 深海之子 | 钓到海洋之心 | 稀有以上概率 +20% |
| 🐉 传说猎人 | 累计钓到 5 条传说鱼 | 大体型概率 +10% |
| ✈️ 空军司令 | 空军/跑鱼/收杆过早累计 100 次 | 挂鱼饵时间 -3s |
| 📖 图鉴大师 | 集齐全部鱼类 | 出售金币 +10% |

## 配置

- 锅巴：可修改开关、钓鱼节奏、各项概率、体型、警局奖励、排行人数、群黑白名单。
- 手动：`config/default_config/` 为默认配置，复制到 `config/config/` 后修改。
  - `config.yaml` 按字段合并，只写要改的项即可
  - `items.yaml`（物品池）、`titles.yaml`（称号）、`help.yaml`（帮助图）整份替换

## 数据

用户存档位于 `data/Fishing_<QQ号>.yaml`，所有群共享。
QQBot 协议下已绑定 QQ 的用户使用 QQ 号，未绑定时使用 openid。

## 按钮

仅 QQBot 协议（[QQBot-Plugin](https://github.com/Tomato-0914/QQBot-Plugin)）会附带按钮，其他协议不发送。
“收杆”按钮仅限抛竿者本人点击。

# 渔具图片

把图片放进对应部位的文件夹，图片会自动替换渔具工坊、强化结果、#我的渔具、#钓鱼信息 里的 SVG 图标，**不需要改代码，也不用重启**（下次出图时生效）。

| 文件夹 | 部位 |
| --- | --- |
| `rod/` | 鱼竿 |
| `line/` | 鱼线 |
| `hook/` | 鱼钩 |
| `float/` | 浮漂 |
| `net/` | 鱼护 |

## 文件名

- `1.png` ~ `20.png`：某一阶专用的图片（例如 `rod/5.png` 是寒玉鱼竿）
- `default.png`：这个部位所有阶位共用的图片

查找顺序：`<阶位>.png` → `default.png` → 内置 SVG。所以可以只放一张 `default.png`，再给个别阶位单独做图。
支持 `.png`、`.webp`、`.jpg`。

## 建议规格

- 透明背景的正方形图片，256×256 左右
- 图标主体尽量撑满画面，四周少留白（图片会按比例缩放到卡片里）

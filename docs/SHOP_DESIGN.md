# 🏪 渔具商店设计方案（草案）

> 状态：**已确认并实现**。后续调整：每类渔具上限由 5 级提升到 **10 级**（Lv6~10 见 `shop.yaml`）；渔具的稀有度效果改为**分档加成**（boostN ~ boostUR，按百分点直接加到各稀有度，从空军→垃圾→普通扣除），取代原来鱼竿的相对倍率与浮漂的空军减少。后续调整：渔具升级移到 **渔具工坊**（`#渔具工坊`），**鱼饵商店**（`#鱼饵商店`，原名渔具商店，旧指令仍可用）只卖鱼饵。
>
> 原确认：确认结果：“鱼获”即鱼护；采用升级制；加入断线机制；价格按本方案；鱼钩、耐久度暂不做；名称不改。
> 原则：参考现实中渔具的材质与作用，但名称、数值、效果都是游戏化的原创设计，不使用任何真实品牌或型号。

---

## 一、设计思路

现实里每样渔具解决一个问题，游戏里也让每样渔具只负责一类效果，互不重复，玩家能清楚地知道“想要什么就升级什么”：

| 渔具 | 现实中的作用（参考） | 游戏中的效果 |
| --- | --- | --- |
| 🎣 鱼竿 | 材质从竹、玻璃纤维到高模量碳素，越来越轻、越硬、越灵敏，能驾驭更大的鱼 | **稀有度**、**大体型**概率提升 |
| 🧵 鱼线 | 尼龙线弹性大但粗，碳氟线隐蔽耐磨，编织线同粗细下拉力最强 | 降低大鱼 / 稀有鱼的**断线**概率（新机制，见第三节） |
| 🎈 浮漂 | 材质越灵敏，越能看清细微的鱼口，少错过咬钩 | **空军**概率降低、**收杆时间**延长 |
| 🪱 鱼饵 | 活饵通杀、腥香饵诱鱼、活虾吸引掠食性大鱼 | 消耗品，**每种效果不同**，同一时间只用一种 |
| 🧺 鱼护 | 更大更结实的鱼护能装更多鱼，活水鱼护让鱼保持新鲜 | **容量**提升，高级鱼护**出售加成** |

> 你写的“鱼获”我理解为“鱼护”（装鱼的网兜，对应现在的背包容量）。【待确认】

## 二、等级与价格

### 规则

- 每类渔具 5 个等级，颜色沿用稀有度：⚪ Lv1 普通 / 🟢 Lv2 优良 / 🔵 Lv3 稀有 / 🟣 Lv4 史诗 / 🟡 Lv5 传说。
- 新玩家默认拥有全部 **Lv1**，不用买。
- **升级制**：必须拥有上一级才能买下一级，买了自动装备。高级严格优于低级，所以不需要切换装备。【待确认】
- 不能卖回，不会损坏（不做耐久度）。【待确认】

## 三、新机制：断线

现在大鱼和小鱼一样，收杆就到手，鱼线就没有意义。加入断线：收杆时，**大体型**或**史诗以上**的鱼有一定概率挣断鱼线跑掉，还会告诉你跑掉的是什么，增加一点遗憾和刺激感。

| 情况 | 基础断线概率 |
| --- | --- |
| 史诗 SSR | 6% |
| 传说 UR | 12% |
| 大体型 | 额外 +4% |
| 普通 / 优良 / 稀有中小体型、垃圾、隐藏款 | 0（不惩罚） |

例：Lv1 尼龙线钓到大体型传说鱼，断线概率 16%；换成 Lv5 龙筋线只有 1.6%。

断线计入“跑鱼”统计（空军司令称号进度），鱼饵照常消耗。

```
💥 啪！鱼线断了！
🐲 一条【传说】龙王虾（大）拖着鱼钩消失在水里……
💡 升级鱼线可以降低断线概率
```

【待确认】这是新增的惩罚机制。不想要的话，鱼线可以改成“收杆时间 + 大体型”，但会和浮漂、鱼竿的效果重叠。

## 四、数值平衡

- **目前收入**：平均每竿约 20 金币，鱼饵成本 2 金币。
- **节奏**：
  - 四件 Lv2 合计 1,300 金币，大约钓 70 竿，第一个晚上就能买齐。
  - 四件 Lv3 合计 5,200，需要几天。
  - 全部 Lv5 合计 68,500，在群里正常玩要几周。
- **效果上限**：渔具、称号、打卡幸运叠加后，概率仍需有底线，避免数值失控：
  - 空军最低 3%，垃圾最低 5%，普通鱼最低 5%（新增 `limits` 配置）。
  - 举例：Lv5 鱼竿 + 深海之子称号 + 大吉 + 金丝秘饵，稀有以上概率合计提升约 73%。传说鱼从 1.94% 升到约 3.4%，仍然是稀有事件。
- 所有价格和效果都写在 `config/default_config/shop.yaml`，可以自己调整。

## 五、指令与界面

| 指令 | 说明 |
| --- | --- |
| `#渔具商店` | 商店图片：四类渔具的当前等级、下一级价格与效果，以及鱼饵列表 |
| `#升级鱼竿` / `#升级鱼线` / `#升级浮漂` / `#升级鱼护` | 购买下一级 |

| `#使用鱼饵 种类` | 切换当前鱼饵 |
| `#我的渔具` | 装备面板：每件渔具的等级与效果、鱼饵库存、当前总加成 |

- **抛竿提示**：增加一行当前装备，例如 `🎣 碳纤竿 · 🧵 编织线 · 🎈 纳米漂 · 🪱 蚯蚓（剩 18）`。
- **QQBot 按钮**：
  - 商店：`[升级鱼竿] [升级鱼线]` / `[升级浮漂] [升级鱼护]` / `[买鱼饵…] [我的渔具]`。
  - 鱼饵：每种一个“使用”按钮。

## 六、数据与兼容

- 存档新增：
  - `gear: { rod: 1, line: 1, float: 1, net: 1 }`
  - `baits: { basic: N, worm: N, ... }`
  - `baitUse: "basic"`
- 老用户：全部渔具记为 Lv1，原有的 `bait` 数量转为 `baits.basic`。
- `config.yaml` 中的 `bagLimit` 改为 Lv1 鱼护的容量，高级鱼护按 `shop.yaml` 中的容量计算。

## 七、可选扩展（本期不做）

- 🪝 **鱼钩**：降低“鱼跑了”的概率（钩越锋利越不易脱钩）。
- 🛠️ **耐久度**：渔具会磨损，需要花金币维修，作为长期的金币消耗。
- 🎁 **限定渔具**：节日或活动限定的外观款，效果与同级相同。

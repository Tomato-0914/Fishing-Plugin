# 与 Gi-plugin 钓鱼 / 每日打卡的对比

参考仓库：https://github.com/qiannqq/Gi-plugin（`apps/鱼.js`、`apps/每日打卡.js`、`fish_cse/default.js`）

## 钓鱼

| 功能 | Gi-plugin | Fishing-Plugin |
| --- | --- | --- |
| 咬钩时间 | 0~60s 均匀随机 | 3~18s 三角分布（中间更常见），可配置 |
| 收杆窗口 | 10~30s 随机 | 固定 15s（称号可延长） |
| 空军 | 10% 特殊事件池（空军 65% / 鲨鱼 30% / 炸弹 5%） | 15%，另有 20% 海洋垃圾 |
| 物品 | 鱼名 + 固定价格（配置表） | 7 种稀有度 + 小/中/大体型 + 重量 |
| 二次收杆 | 价格 ≥15 的鱼 30% 概率要求 10s 内再收一次 | 无 |
| 特殊事件 | 鲨鱼（冷却翻倍，可花钱加急治疗）、炸弹（扣鱼竿耐久） | 隐藏款：人民碎片（报警领奖）、海洋之心 |
| 鱼竿 | 有耐久度，每竿 -0.1%~10%，坏了要修 | 无 |
| 鱼饵 | 商店卖“幸运鱼饵”（5 杆稀有率提升） | 普通鱼饵：每竿消耗 1 个，2 金币/个 |
| 商店 | 小卖铺（修鱼竿、幸运鱼饵等） | `#购买鱼饵` |
| 捕捞 | `#捕捞` 另一种获取方式 | 无 |
| 背包 | 水桶 | 鱼护（容量上限、图片展示） |
| 出售 | `#出售 鱼*数量`、一键出售 | `#出售 名称 [数量]`、一键出售、清理垃圾 |
| 排行 | 财富榜（金币） | 本群日/周/月榜、全服总榜（按钓获价值） |
| 昵称 | `#修改钓鱼昵称` | 自动读取群名片（QQBot 未绑定用户显示“钓友xxxx”） |
| 成长 | 无 | 8 个称号，带永久效果 |
| 数据存储 | Redis + JSON | 每人一个 YAML 文件 |
| 按钮 | 无 | QQBot 按钮 |

## 每日打卡

| 功能 | Gi-plugin | Fishing-Plugin（已移植） |
| --- | --- | --- |
| 幸运值 | 0~100 随机，每天一次 | 相同 |
| 低幸运值劝退 | ≤10 或 20% 随机，需再发一次确认 | ≤10 时劝退（可配置，0 关闭） |
| 今日欧皇 / 非酋 | 当天首个 ≥95 / ≤5 | 相同，阈值可配置 |
| 幸运值排行榜 | 全服欧皇/非酋榜（需自己先打卡） | 群内为本群榜，私聊为全服榜 |
| 历史幸运值 | 文本文件 | 存档里保留最近 30 次 |
| 看别人的卡 | `#让我看看你的卡 @某人` | 相同 |
| 打卡图片 | 有 | 文字 + 进度条 |
| 对玩法的影响 | 无（纯展示） | **幸运等级轻微影响当天钓鱼概率**，按幸运值送对应等级的鱼饵、记录连续打卡天数 |

### 幸运等级与钓鱼影响（默认）

| 幸运值 | 等级 | 当天钓鱼影响 |
| --- | --- | --- |
| 90~100 | 🌟 大吉 | 稀有以上概率 +10%（相对值），空军 -2% |
| 70~89 | 🍀 吉 | 稀有以上概率 +5% |
| 30~69 | 🌤️ 平 | 无 |
| 10~29 | 🌧️ 凶 | 空军 +2% |
| 0~9 | ⛈️ 大凶 | 空军 +3%，垃圾 +2% |

任何结果的概率变化都不超过 5 个百分点。不打卡没有影响。

## 后续可以考虑借鉴的

- **二次收杆**：大鱼挣扎需要再收一次，增加操作感
- **随机事件**：鲨鱼咬伤（冷却翻倍）等，给空军增加花样
- **幸运鱼饵**：商店道具，几杆内提高稀有率，给金币更多用途
- **修改钓鱼昵称**：QQBot 协议拿不到昵称，可以让用户自己设置

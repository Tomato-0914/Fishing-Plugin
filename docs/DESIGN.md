## 五、钓鱼流程

### 5.1 状态机

```
空闲 ──#钓鱼──▶ 等待咬钩（随机 3~18s，不提示）
                    │ 时间到
                    ▼
               “🐟 浮漂动了！快收杆！” + [收杆]按钮
                    │
        ┌───────────┼─────────────────┐
  窗口内#收杆   窗口超时（默认 15s）   提前#收杆（咬钩前）
        │           │                 │
     结算物品    “鱼跑了~”          “太心急了，什么都没钓到~”
        │           │                 │
        └──────▶ 进入冷却（默认 10s）◀┘
```

### 5.2 时间设计

- **咬钩时间**：在 `[3, 18]` 秒内随机（可在锅巴改，硬上限 30s）。
  【建议】不使用纯均匀分布，而是“两个均匀随机数取平均”的三角分布：大多数在 8~13s，偶尔很快或很慢，体验更像真实钓鱼。
- **收杆窗口**：咬钩提醒后 15s 内收杆有效。（QQBot 被动回复有效期 5 分钟，完全够用。）
- **冷却**：一次钓鱼结束后 10s 才能再次抛竿，防刷屏。
- 同一用户同时只能有一根竿；跨群也算同一根（数据共享）。

【待确认】你说“一段时间后提醒用户收杆”，我理解为**需要用户手动收杆**（有操作感，并加入“鱼跑了”机制）。
如果你更想要“提醒后自动出结果”，告诉我即可，改为只发一条结果消息。

### 5.3 结算消息示例

```
🎣 收杆！
━━━━━━━━━━━━
🐟 【稀有】金枪鱼  12.6kg
💰 价值：380 金币
━━━━━━━━━━━━
已放入鱼获，发送 #鱼获 查看
[再来一竿] [我的鱼获] [一键出售]
```

```
🎣 收杆！
👟 【垃圾】一只破拖鞋
💰 价值：0 金币（海洋垃圾，已为你回收，感谢保护海洋~）
```

```
🎣 收杆……什么都没钓到~ 🌊
```

## 六、物品池与稀有度

### 6.1 分类概率（默认值，锅巴可改，总和 100%）

| 结果 | 概率 | 售价区间 |
| --- | --- | --- |
| 🌊 空军（什么都没钓到） | 15% | — |
| 🗑️ 海洋垃圾 | 20% | 0 |
| ⚪ 普通 N | 30% | 5 ~ 30 |
| 🟢 优良 R | 18% | 30 ~ 100 |
| 🔵 稀有 SR | 10% | 100 ~ 400 |
| 🟣 史诗 SSR | 5% | 400 ~ 1500 |
| 🟡 传说 UR | 1.95% | 1500 ~ 6000 |
| ❓ 隐藏「人民碎片」 | **0.05%（约 1/2000）** | 警局奖励 50000 |

抽取方式：先按分类概率抽稀有度，再在该稀有度内按物品自身权重抽具体物品。

【建议】**重量浮动**：鱼类有重量范围，售价 = 基础价 × (实际重量 / 平均重量)，同一种鱼也有大小之分，增加刷“大鱼”的乐趣；排行榜可附带“最大一条鱼”。垃圾和隐藏款没有重量。

### 6.2 物品示例（`items.yaml`，可自由增删）

| 稀有度 | 物品 |
| --- | --- |
| 垃圾 | 破拖鞋、旧衣服、手电筒、塑料袋、易拉罐、破渔网、旧轮胎、生锈的鱼钩、漂流瓶（空的）、断掉的鱼竿 |
| N | 小鲫鱼、泥鳅、小河虾、麦穗鱼、小黄鱼、蛤蜊 |
| R | 鲤鱼、草鱼、鲈鱼、河蟹、小龙虾、带鱼 |
| SR | 黄花鱼、大闸蟹、石斑鱼、鳗鱼、对虾、鱿鱼 |
| SSR | 金枪鱼、帝王蟹、龙虾、三文鱼、比目鱼 |
| UR | 中华鲟（仿真模型 / 不可出售？见下）、皇帝蟹、金龙鱼、深海巨鱿、远古腔棘鱼 |
| 隐藏 | 人民碎片（浮尸） |

【待确认】UR 里若出现保护动物（如中华鲟），是否改成“放生获得奖励”的设定？我默认**不放保护动物**，避免争议。

`items.yaml` 结构示例：

```yaml
- id: tuna
  name: 金枪鱼
  emoji: 🐟
  rarity: SSR
  price: 800          # 基础售价
  weight: [5, 30]     # kg，可选
  chance: 10          # 同稀有度内权重
  desc: 深海里的速度之王
```

### 6.3 隐藏款「人民碎片」

- 钓到后**不进入背包**，直接触发事件：

```
🚨 你钓上来一个……不对劲的东西
❓ 【隐藏】人民碎片
你颤抖着拨打了 110……
👮 警方已到场处理，感谢你的配合！
🏅 获得「热心市民」奖励：50000 金币
```

- 记入图鉴与个人统计（`hidden` 次数），可在排行榜/个人信息中显示 🏅 徽章。
- 奖励金额计入当期排行（【待确认】是否计入；默认计入，这是全服最大惊喜）。
- 【建议】全服公告：钓到时在本群额外艾特一句“恭喜 xxx 成为热心市民”。

## 七、鱼获（背包）功能

- `#鱼获`：puppeteer 渲染图片，按稀有度分组，每行显示 emoji、名称、数量、单价、小计；底部显示**全部出售可得金币**与当前余额。
  数据太多时只显示前 N 种，其余合计一行。
- `#出售 金枪鱼 3` / `#出售 金枪鱼`（全部）/ `#一键出售`（全部有价值物品）。
- 垃圾出售价恒为 0，`#一键出售` 不处理垃圾，提示使用 `#清理垃圾`。
- 背包上限【建议】200 件，满了提示出售，防止存档无限增长。
- 带重量的鱼按“单条”存储售价，同名合并显示数量与总价。

## 八、排行榜

### 8.1 统计口径

【待确认】默认按 **当期钓获总价值（金币）** 排名（钓到即计入，不受是否出售影响；垃圾为 0）。
备选：按钓鱼次数 / 钓获数量 / 最大单条重量。可以在锅巴里切换。

### 8.2 周期

| 榜单 | 周期 key | 重置时间 |
| --- | --- | --- |
| 日榜 | `2026-11-02` | 每天 00:00 |
| 周榜 | `2026-W45`（ISO 周，周一开始） | 每周一 00:00 |
| 月榜 | `2026-11` | 每月 1 日 00:00 |

采用**惰性重置**：用户存档里记录 `{ key, value, count }`，读写时若 key 已过期就清零，无需定时任务。

### 8.3 范围

需求中的“好友排名”：QQ 群里我理解为**本群排名**。
- 用户每次在某群钓鱼时，把群号记入存档 `groups` 列表。
- `#钓鱼日榜` 只统计在本群钓过鱼的人；`#钓鱼总榜` 统计全部存档。
- 展示前 10 名 + 自己的名次（图片）。
- 读取方式：启动时扫描 `data/` 建内存索引，之后每次写存档同步更新索引，查榜不再读盘。

> QQBot 协议下拿不到昵称和头像：已绑定 QQ 号的用户用 QQ 头像；未绑定的显示“钓友xxxx”（openid 末 4 位）。用户在其他协议发言时会自动记录昵称。

## 十二、Button 按钮

### 12.1 发送规则

```js
// components/Button.js
export function withButtons(e, msg, rows) {
  if (!Config.button || e.bot?.adapter?.id !== "QQBot" || typeof segment.button !== "function")
    return msg                         // 非 QQBot 直接不附加，避免报错
  return [msg, segment.button(...rows)].flat()
}
```

- 群聊 `input` 按钮一律 `send: false`（QQBot 文档要求）。
- **“收杆”按钮加 `permission: e.user_id`**，只有抛竿者本人能点，防止别人帮你收杆。

### 12.2 按钮布局

| 场景 | 按钮 |
| --- | --- |
| 抛竿后 | 无（等待中不打扰） |
| 咬钩提醒 | `[🎣 收杆]` callback `#收杆`，permission = 本人 |
| 收杆结果 | `[再来一竿]` callback `#钓鱼` ｜ `[我的鱼获]` callback `#鱼获` ｜ `[一键出售]` callback `#一键出售` |
| 空军 / 鱼跑了 | `[再来一竿]` ｜ `[钓鱼帮助]` |
| 鱼获图 | `[一键出售]` ｜ `[出售…]` input `#出售 ` ｜ `[清理垃圾]` ； 第二行 `[日榜]` `[周榜]` `[月榜]` |
| 排行榜 | `[日榜]` `[周榜]` `[月榜]` ｜ `[去钓鱼]` |
| 帮助图 | `[开始钓鱼]` `[我的鱼获]` `[排行榜]` ｜ `[项目地址]` link 到 GitHub |
| 更新 | `[确认更新]` callback `#钓鱼更新` permission = `master` |
